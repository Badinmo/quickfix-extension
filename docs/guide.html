Installing QuickFix

QuickFix fixes grammar and translates text right where you're typing — a FreshService ticket, a webmail reply, anywhere. This walks through every click, start to finish, in about ten minutes.

A

Get a free Gemini API key

QuickFix uses Google's Gemini AI to do the actual writing work. You need a personal key so it can talk to Gemini on your behalf — think of it as a password just for this.

  1. 1

    Go to Google AI Studio and sign in with your Google account.

    aistudio.google.com/apikey

  2. 2

    Click Create API key.

    If it asks you to pick a project, the default one Google offers is fine.

  3. 3

    Copy the key it gives you — a long string starting with AIza…

    Paste it somewhere temporary (Notepad is fine). You'll need it again in Part C.

Keep this key private

Treat it like a password — anyone with it can use your free Gemini quota. QuickFix stores it only on this computer and never shares it with anyone but Google's API.

B

Install the extension

QuickFix isn't in the Chrome Web Store — it's loaded straight from its folder, which takes four clicks and never expires.

  1. 1

    Open a new tab and type this into the address bar, then press Enter:

    edge://extensions

    Using Chrome instead? Use chrome://extensions — everything else is identical.

  2. 2

    Find the Developer mode switch (usually bottom-left, or top-right in Chrome) and turn it on.

  3. 3

    Click the Load unpacked button that appears.

  4. 4

    In the folder picker, select this whole folder and click Select Folder:

    C:\Users\albadinm\quickfix-extension

    Select the folder itself — don't open it and pick a file inside.

You'll know it worked

A card for QuickFix — Inline Grammar & Translate appears in the list, with a small indigo checkmark icon, and a settings tab opens automatically — that's Part C, next.

On a managed work laptop? Clicking Load unpacked may do nothing

Organisation-managed devices often block extensions outright — the button clicks but no folder picker opens, with no error message. This isn't something to work around yourself; it's a decision for IT, and allowlisting alone often isn't the whole fix — many organisations separately block Developer-Mode loading itself as an install method, which no allowlist entry unblocks.

If that's the situation, the working path on a managed device is usually a private, unlisted listing in the Chrome Web Store or Microsoft Edge Add-ons store instead of Load unpacked — installed like any other extension, so the Developer-Mode block never comes into play. That's a separate one-time setup step — see Part G onward, below — rather than something to solve from this guide's Part B. Once it's live, IT allowlists the Store-assigned ID and you install from the private Store link instead of steps 1–4 above.

C

Connect your key

One-time setup so QuickFix knows which Gemini account to use.

  1. 1

    On the QuickFix settings tab (or click the puzzle-piece icon in the toolbar, then QuickFix, then Settings), find the API key box under "Gemini".

  2. 2

    Paste the key you copied in Part A.

  3. 3

    Click Test connection — it should reply with a corrected sentence in under a couple of seconds.

  4. 4

    Click Save settings.

    While you're there: Translation → Translate to is set to Arabic by default — change it if you'd rather translate into something else.

D

Try it out

A safe practice page before you use it somewhere that matters.

  1. 1

    Open this file in your browser (drag it into a new tab, or use Ctrl + O from within the browser):

    C:\Users\albadinm\quickfix-extension\test\playground.html
  2. 2

    Click and drag to select a sentence in the first box ("textarea").

  3. 3

    Press Alt + G to fix grammar, or Alt + T to translate.

    A small "Fixing…" pill appears for a second, then your selected text is replaced.

Nothing happened?

Files opened from disk need one extra permission. Go back to edge://extensions, click Details on the QuickFix card, and turn on Allow access to file URLs. Then reload the practice page. This step is only needed for files on your own computer — ordinary websites don't need it.

E

Everyday use

Once it's set up, this is all there is to it — on FreshService, Outlook on the web, or almost any other text box.

  1. 1
    Select the text you want to change.
  2. 2
    Press a shortcut, right-click and choose QuickFix, or click the small toolbar that pops up next to your selection.
  3. 3
    The new text appears in place of the old. Not happy with it? Ctrl + Z undoes it, exactly like any other edit.

Two things worth knowing

New Outlook desktop app doesn't work. QuickFix only runs inside a browser tab — so it works on Outlook on the web (outlook.office.com), but not the separate New Outlook Windows app.

Selected text is sent to Google. Whatever you select is processed by Google's Gemini service to fix or translate it. If you're on an NHS trust system, check your Information Governance policy before using it on anything that could contain patient-identifiable information.

F

If something's wrong

Common snags and the one-line fix for each.

What you seeWhat to do
Nothing happens when I press the shortcut Reload the page you're testing on — the extension only wakes up on pages loaded after it was installed or updated.
"Select the text you want QuickFix to work on first" Highlight some text before pressing the shortcut. In rich-text boxes (like an email editor) this is required — QuickFix won't guess.
"That Gemini API key was rejected" Re-copy the key from Part A — it's easy to grab a trailing space by accident. Paste it fresh into Settings.
Shortcut does something else on a website That site has claimed Alt+G or Alt+T for itself. Use the right-click menu instead, or change the shortcut at edge://extensions/shortcuts.
Text is replaced but the site doesn't seem to notice Click elsewhere on the page once, or try Send/Save again — some sites take a moment to register the change.
G

Prepare a submission

One-time prep shared by both stores below — do this once, then Parts H and I each take about ten minutes on top.

Why both?

On a managed Edge browser, IT commonly locks the "allow extensions from other stores" setting off — meaning a Chrome Web Store item won't install in Edge even if it's allowlisted by ID. If your work browser is Edge, Part I is the one that actually matters; Part H covers Chrome. Doing both means you're covered regardless of which one IT ends up unlocking.

  1. 1

    Rebuild the submission package (needed once now, and again after any future code change):

    powershell -ExecutionPolicy Bypass -File tools\build-package.ps1

    Run from inside C:\Users\albadinm\quickfix-extension. It writes dist\quickfix-webstore.zip — the file both stores want uploaded. This is the only file either dashboard needs from you.

  2. 2

    Host the privacy policy somewhere public. Both stores require a live URL for it, since this extension sends selected text to an external API (Gemini). The easiest way, using a free GitHub account:

    Go to gist.github.com → sign in (or create a free account) → paste the contents of docs\privacy-policy.md → name the file privacy-policy.md → click Create public gist → on the page that opens, click the Raw button → copy that page's URL. That's your privacy policy URL — keep it handy for both Part H and Part I.

    C:\Users\albadinm\quickfix-extension\docs\privacy-policy.md
H

Publish to the Chrome Web Store

Creates a private, unlisted listing — never publicly searchable, installable only by people you allow.

  1. 1

    Open the Chrome Web Store Developer Dashboard and sign in with a Google account:

    chrome.google.com/webstore/devconsole

    If that address has moved, search "Chrome Web Store developer dashboard" — Google occasionally changes it.

  2. 2

    First time only: pay the one-time $5 developer registration fee when prompted. It covers this and any future item on the same account.

  3. 3

    Click New Item, then upload the zip from Part G:

    C:\Users\albadinm\quickfix-extension\dist\quickfix-webstore.zip
  4. 4

    On the Store Listing tab, fill in the title, summary, description, category, and language, and upload the screenshot — all written out ready to paste in:

    docs\store-listing.md dist\screenshot-settings.png
  5. 5

    On the Privacy practices tab, paste the single-purpose description and permission justifications from that same file, answer the data-usage questions (it transmits your selected text off-device to Gemini — answer truthfully), and paste the privacy policy URL from Part G.

  6. 6

    On the Distribution tab, set visibility to Private or Unlisted — never Public.

    Private restricts installs to specific Google accounts you list (add your own). Unlisted means anyone with the direct link can install it, without being individually added. If you only ever use one Google account, either works; Unlisted is the more convenient of the two.

  7. 7

    Click Submit for review. You'll get an email once it's approved (or if the reviewer needs changes).

  8. 8

    Once approved, open the item's dashboard page and copy its extension ID and Store URL.

This ID is new — not the one already given to IT

The Store assigns its own permanent ID the moment you first upload, and ignores the ID pinned in the extension's manifest entirely. Send this new ID to whoever manages your organisation's allowlist — the earlier one only applies to unpacked/Developer-Mode loading, which is a different install path.

I

Publish to Microsoft Edge Add-ons

The same idea as Part H, on Microsoft's own dashboard — likely the one that actually matters if your work browser is Edge.

  1. 1

    Open the Microsoft Edge Add-ons developer dashboard (part of Partner Center):

    partner.microsoft.com/dashboard/microsoftedge
  2. 2

    Sign in with a Microsoft account and register as an extension developer — free, no fee.

    Use a personal Microsoft account (e.g. an outlook.com/hotmail address) rather than your NHS work account, if you have one — it keeps this personal project separate from your trust's own Microsoft tenant.

  3. 3

    Click Create new extension, and upload the exact same zip from Part G — no changes needed, Edge accepts the same package format as Chrome:

    C:\Users\albadinm\quickfix-extension\dist\quickfix-webstore.zip
  4. 4

    On the Properties tab, set category to Productivity and paste the same privacy policy URL from Part G.

  5. 5

    On the Store listings tab, fill in the display name and description from docs\store-listing.md, and upload the same screenshot as Part H:

    dist\screenshot-settings.png
  6. 6

    Set Visibility to Private/Unlisted (wording varies by dashboard version) — not Public.

  7. 7

    Submit for certification. Microsoft's review is separate from Google's — expect roughly a week, though it varies.

  8. 8

    Once certified, copy the item's extension ID and Store URL from the dashboard.

Installing once it's live

Open the Edge Add-ons URL in Edge and click Get. If your organisation blocked "Load unpacked" but allows Microsoft-vetted Edge Add-ons store items, this is the path that actually gets QuickFix running on your work laptop — give IT this ID (separate from both the unpacked ID and the Chrome Web Store ID) to allowlist.

Extension folder: C:\Users\albadinm\quickfix-extension — open README.md inside it for the technical write-up.
